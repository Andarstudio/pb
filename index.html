How to install PrivBrowser

1

Download

Click the download button above to download the PrivBrowser ZIP package.

2

Extract

Right-click the downloaded ZIP file and choose Extract All to extract the PrivBrowser files.

3

Open

Open the extracted folder and double-click the PrivBrowser EXE to start the installer/browser.
